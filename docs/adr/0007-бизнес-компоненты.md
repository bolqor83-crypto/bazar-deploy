# ADR 0007: Бизнес-компоненты дизайн-системы

- **Статус:** принято (Промт 6, часть D)
- **Дата:** 2026-11-11

## Контекст

Экраны каталога, заказов и доставки (следующие промты) состоят из
повторяющихся блоков: цены, наличие, статусы, карточки сторон, выбор
точки и способа получения. Чтобы не плодить разнобой, блоки вошли в
дизайн-систему `@bazar/ui` на общих правилах: presentation-only,
данные через пропсы, только токены, a11y, без emoji.

## Состав (10 компонентов)

| Компонент        | Назначение                                          |
| ---------------- | --------------------------------------------------- |
| PriceDisplay     | цена: копейки → рубли, U+202F, tabular-nums, скидка |
| QuantitySelector | количество: кнопки 48×48, min/max                   |
| StockIndicator   | наличие: in / low / out                             |
| OrderStatus      | 11 статусов заказа → Badge (подписи в константах)   |
| ProductCard      | карточка товара витрины                             |
| ProductRow       | строка товара: «N × цена», сумма                    |
| OrderSummary     | сводка заказа: позиции + итого                      |
| PartyCard        | контрагент: инициалы, рейтинг, BadgeCheck           |
| LocationSelector | выбор точки: триггер + шит, «Вся сеть»              |
| DeliveryCard     | способ получения: самовывоз / доставка              |

## Ключевые решения

### Деньги — целые копейки

Все суммы передаются в копейках (`priceKopecks: number`): без
плавающей точки, без накопления ошибок округления. Форматирование —
`formatPrice()` из PriceDisplay: разделитель групп и пробел перед
₽ — узкий неразрывный **U+202F** (не разрывает сумму при переносе
строк), запятая — десятичный разделитель, цифры — табличные
(`tabular-nums`), суммы в столбик не «пляшут». Скидка — бейдж «−N%»
варианта warning: янтарь, красный запрещён.

### Статусы заказа — константы

11 статусов жизненного цикла: draft, new, confirmed, assembling,
ready, in_delivery, delivered, completed, cancelled, returned,
disputed. Русские подписи (`ORDER_STATUS_LABELS`) и маппинг на
варианты Badge живут рядом с компонентом — экраны не дублируют текст
и не выбирают цвета.

### Инициалы и рейтинг

`initialsOf()` срезает ведущие не-буквы («Сеть «У дома»» → «СУ»);
рейтинг форматируется с запятой («4,8»). Верификация — иконка
BadgeCheck цветом info.

### Расширение Card

`Card` получил prop `selected` (accessibilityState для выбираемых
карточек — DeliveryCard). Остальные токены и компоненты не менялись.
