# ADR 0013: UX-долги Промта 12 — склад, типографика, формы, навигация

**Статус:** принят (Промт 12, Часть E)
**Контекст:** VLM-аудит склада Промта 11b — 55–76 при пороге 80;
накоплены UX-долги: противоречивая типографика, отсутствие
базовых полей форм, перегруженная навигация оптовика, рамки полей
в покое ниже 3:1 (долг из ADR 0002).

## Решения

### 1. Склад: строки вместо карточек (Часть A)

- Сводка — одна панель-полоса 56 с метриками «Позиций · Мало · Нет»
  (key-value, tabular-nums) вместо трёх карточек.
- Список — компактные строки 64 (фото 40 круглое, остаток numberL
  справа с точкой-индикатором), разделитель — 1px Divider, не
  карточная обёртка. Без резерва раскладка «Доступно» под остатком
  не дублирует число (доступно = физическому).
- FAB убран: «Добавить приход» — primary-кнопка в панели
  управления + шит выбора позиции. FAB перекрывал последнюю строку.
- Фильтры и поиск — одна строка 36 (FilterChip size="sm" +
  SearchBar compact).
- Пустое состояние — compact (иконка 40, прижато к верху).
- Деталь позиции: панель остатка 80 (3 цифры numberL), 4 действия в
  один ряд (иконка 18 + micro-метка, высота 48; полные подписи не
  помещаются в 4 колонки на 360 — «Корректировка» → «Коррекция»),
  журнал — строки 56.
- Форма движения: полноэкранный маршрут (уже был), добавлены чипы
  типа (4 в ряд, переключение без возврата; «Перемещение» ведёт в
  transfer), причина multiline 3 строки, «Сохранить» — primary lg.

### 2. Типографика: ревизия шкалы (Часть B)

- h1 28→26, caption 13→14 (LH 18→20), добавлены numberXl (32/40/700)
  и numberL (24/32/700) — табличные цифры автоматически.
- Правила: body (17) — минимум смыслового; caption (14) — подписи и
  ошибки полей; micro (12) — только метки. Пройдены все экраны:
  смысловые bodySmall/micro заменены (описания EmptyState/ErrorState
  → body, адреса/подписи → caption, заголовки строк → bodyStrong).
- Контракт шкалы — статический тест `tokens/__tests__/typography.test.ts`.

### 3. Формы: базовая библиотека (Часть C)

Select (combobox + шит), Checkbox (24×24 r4), Radio (24), Switch
(48×28, thumb 24), DatePicker (календарь 7×6 с понедельника, «Сегодня
/ Отмена / Применить», min/max). А11y: RN accessibilityState не
поддерживает `on` — используется `checked` (ARIA-корректно для
switch). 31 тест.

### 4. Навигация: «Все инструменты» (Часть D)

- Шит «Ещё» (8 пунктов списком) заменён полноэкранным экраном
  `/<роль>/more`: группы Торговля / Склад / Клиенты / Финансы /
  Аккаунт, поиск по подстроке, строки 56, бейдж непрочитанных
  уведомлений.
- Таб-бар: подпись вкладки осталась «Ещё» (опция из ТЗ), иконка
  заменена на LayoutGrid; вкладки растут от контента — «Предложения»
  больше не обрезается на 360–390. Для store_owner — тот же экран
  со своими группами; у customer/carrier «Ещё» нет.
- Новый рабочий экран «Движения» — общий журнал `/stock/movements`
  (без фильтра по офферу) поверх существующего API (ADR 0012),
  строками MovementRow с offerTitle.
- Заглушки (Промт 13+): wholesale notes / debts / organization / staff.

### 5. Контраст рамок ≥ 3:1 (Часть E)

- **Отклонение от буквальных значений промта.** Указанные в ТЗ
  цвета (#C9D2C9 light / #3E4440 dark) дают только 1.46:1 / 1.78:1
  против фонов — порог 3:1 (WCAG 1.4.11) математически недостижим
  с ними. Приняты ближайшие значения с фактическим ≥ 3:1 против
  всех смежных фонов (surface / background / surfaceMuted):
  - light: border #E4EAE4 → **#818880** (3.17–3.64), borderStrong
    #C9D2C9 → **#666D66** (5.32);
  - dark: border #2A2E2B → **#6E746F** (3.09–3.70), borderStrong
    #3E4440 → **#878E88** (4.84).
- Contrast-тест расширен 8 парами рамок (light/dark × 4 фона).
- Следствие: рамки заметно плотнее — принято как цена доступности;
  golden пересняты.

## Последствия

- Все экраны пере-сняты в golden (42 записи, включая 2 новых
  «Инструментов»); pixelmatch tolerance 0.5%.
- Тесты: ~1000+ (unit 829 → ~985, e2e 114 без изменений).
- Golden для «Движений» сознательно не добавлен: журнал изменчив
  (DoD-сценарии пишут движения) — регресс закрыт unit-тестами и
  VLM-аудитом.
- Порог VLM-аудита повышен до 85/100 (медиана 3 прогонов).
