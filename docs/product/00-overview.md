# Обзор продукта «Bazar»

**Bazar** (ранее «АгроМолл») — цифровая торговая экосистема оптового и розничного аграрного рынка. Проект переименован, чтобы не путать его с прежним прототипом «АгроМолл» (v0.8.1), который не используется.

## Четыре участника

1. **Обычный покупатель** — физическое лицо.
2. **Покупатель из точки** — владелец розничной торговой точки.
3. **Оптовый продавец** — продаёт большими партиями через публичный оптовый каталог.
4. **Доставщик** — независимый перевозчик.

## Два торговых контура

| Контур        | Содержимое                                |
| ------------- | ----------------------------------------- |
| **Оптовый**   | Публичный оптовый каталог, оптовые заказы |
| **Розничный** | Витрины торговых точек, розничные заказы  |

Контуры не смешиваются ни в UI, ни в данных.

## Общие принципы

- **Без денег на платформе.** Платформа не принимает и не распределяет деньги — только фиксирует факты оплаты между участниками. Никакого эскроу и кошельков.
- **Офлайн-first.** Приложение обязано быть полезным при слабом сигнале и без сети: пользователь работает на рынке в 4–14 утра, в перчатках, при слабом свете.
- **Репутация из событий.** Доверие к участникам складывается из истории событий (сделки, доставки, выполнения обязательств), а не из заявленных профилей.
