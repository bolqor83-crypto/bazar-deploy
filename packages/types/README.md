# @bazar/types — доменные типы Bazar

TypeScript-типы, разделяемые между `apps/mobile` и `apps/api`.
Workspace-пакет `@bazar/types` (без зависимостей).

## Состав (по доменам)

| Файл               | Домен                                                                       |
| ------------------ | --------------------------------------------------------------------------- |
| `auth.ts`          | `AuthUser`, `AuthError`/`AuthErrorCode`, контракты входа                    |
| `context.ts`       | роли, `Membership`, модель контекста приложения                             |
| `onboarding.ts`    | шаги онбординга                                                             |
| `catalog.ts`       | категории, товары, офферы, POR-контракт (Промт 16)                          |
| `cart.ts`          | корзина, позиции                                                            |
| `order.ts`         | заказы, статусы, события                                                    |
| `seller.ts`        | витрина продавца, его офферы                                                |
| `stock.ts`         | склады, движения, остатки (ADR 0012)                                        |
| `delivery.ts`      | доставки, статусы, лента перевозчика                                        |
| `price-request.ts` | запросы цены, персональные предложения                                      |
| `market.ts`        | константы сетки рынка `MARKET` + маршрут (ADR 0017), аналитика (Промт 18 C) |
| `notification.ts`  | уведомления                                                                 |

## Как расширять

1. Новый домен — новый файл в `src/` + экспорт из `src/index.ts`.
2. **Контракты API дублируются на сервере осознанно**: api не тянет
   workspace-пакет (см. ADR 0008) — при изменении контракта
   меняется и тип здесь, и DTO/api-модуль на сервере. Константы
   (например, `MARKET`) зеркалируются в `apps/api/src/market/market.service.ts`.
3. Статусы и enum-подобные значения — строковые union-типы: в БД
   Prisma они строками (см. `prisma/schema.prisma`), валидация —
   zod/DTO на сервере.
4. Типы — только данные: без функций, зависимостей и UI.
