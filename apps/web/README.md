# @bazar/web — веб-платформа Bazar

Скелет веб-платформы (Промт 6, Часть C). Пакет намеренно пуст:
реализация — **Промт 7**.

## Что здесь сейчас

- `src/index.ts` — заглушка точки входа (см. ADR 0006).
- `tsconfig.json` — те же строгие настройки TypeScript, что и во всём
  монорепо (`tsconfig.base.json`).
- Скрипт `typecheck` включён в общий конвейер `turbo lint typecheck test`
  (13 задач).

## Что будет в Промте 7

- Next.js (App Router) с серверными компонентами.
- Розничная витрина для покупателей: каталог, карточки точек, заказы.
- SSR-безопасные обёртки над сторами `@bazar/ui` и контекстом.
- Подключение реального API (`apps/api`).

## Правила

- Веб-платформа не опережает мобильное приложение: фичи приходят
  после мобильной реализации.
- Дизайн — только на токенах `@bazar/ui`, отдельные стили запрещены.
