## Каталоги

- `audit/` — кадры витрины форм (`/dev/design`) для аудита группы forms:
  полный кадр карточки «Параметры поставки» (clip по границам),
  открытый Select, открытый календарь.
- `preview/` — кадры склада (светлая/тёмная темы) для аудита группы stock.
- `audit-final/` — последний аудит: по 3 прогона на экран, медиана
  (10/13 экранов завершены; typo частично не прошёл из-за 429).
- `audit-final-prev2/`…`audit-final-prev4/` — архивы аудитов
  предыдущих итераций правок (история оценок).

## VLM-аудит: история итераций (медиана 3 прогонов, порог 85)

| Итерация                      | Лучший экран      | Средняя | Прогресс              |
| ----------------------------- | ----------------- | ------- | --------------------- |
| 1–2 (до доработок)            | 76                | ~63     | исходный провал 55–76 |
| 3 — фото, степпер, плотность  | 82 (stock-detail) | ~74     | +11                   |
| 4 — контраст токенов, статусы | 79                | ~72     | +5-около-плато        |
| 5 — disabled, профиль         | 78                | 75      | плато                 |

Вывод: ключевые замечания грейдера закрыты (заглушки-корзины →
реальные фото; обрез цен → юнит под ценой; отсутствующее состояние
«в корзине» → мини-степпер; 3 одинаковых заказа → 6 разных со
статусами; полупустой профиль → сводка операций; серые тексты и
disabled-состояния → контраст ≥ AA). Оценки при этом колеблются
в пределах ±10 между прогонами одних и тех же кадров — потолок
скалярного грейдера ~75–82. Порог 85 как критерий приёма требует
смены метода: чек-лист по критериям (pass/fail) или другая модель —
скалярный шум не позволяет отличить «улучшили» от «не улучшили».
